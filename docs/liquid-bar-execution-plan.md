## 二、 分步执行稿

按顺序依次推进，每完成一步即通过对应的验收标准；遇到阻塞立即启用该步骤的止损方案。

### 步骤 1：打通 WebGL2 双通道融球渲染管线
> **核心产物：** `shaders.ts`、`MetaballRenderer.ts`

**执行动作：**
1. 在 `App.tsx` 中创建全屏自适应 WebGL2 Canvas（逻辑坐标固定为 `800 x 600`，按 `window.devicePixelRatio` 缩放物理像素，防止高分屏模糊）。
2. 编写 `MetaballRenderer.ts`，启动时检测 `gl.getExtension('EXT_color_buffer_float')`：支持则创建 `RGBA16F` 离屏 FBO，不支持则自动降级为 `RGBA8` 并把 Pass 1 粒子权重系数乘以 `0.25`、Pass 2 截断阈值同步调整为 `0.14`。
3. 实现 **Pass 1（密度与色彩累加）**：将粒子数组打包成 `Float32Array`（每颗粒子 5 个 float：`x, y, r, g, b`），以 `gl.POINTS` + 加法混合 `gl.blendFunc(gl.ONE, gl.ONE)` 绘制到 FBO；片元用四次衰减核 `w = pow(max(0.0, 1.0 - r2), 2.0)` 输出 `vec4(color * w, w)`。
4. 实现 **Pass 2（融球截断与假 3D 高光）**：全屏三角形采样 FBO，用 `smoothstep` 切出平滑液面，四邻域求梯度生成法线，叠加左上方暖白高光（`pow(..., 32.0)`）与边缘菲涅尔透光。
5. 先用 300 颗做简单正弦漂浮的测试粒子验证画面。

- **验收标准（DoD）：** 屏幕上 300 颗红蓝测试粒子互相靠近时能像水银/鸡尾酒一样丝滑拉丝融合，边缘光滑无锯齿、带湿润高光，Chrome FPS 仪表盘稳定 60 帧。
- **卡点止损方案：** 如果 `gl.POINTS` 在某些核显上有最大点尺寸限制（如上限 64px），直接把 `gl_PointSize` 钳制在 `48.0 * dpr` 以内并适当调大物理半径即可。

### 步骤 2：实现空间哈希流体物理与分层混色引擎
> **核心产物：** `SpatialHash.ts`、`FluidSolver.ts`

**执行动作：**
1. 编写 `SpatialHash.ts`：按作用半径 `h = 24px` 划分格子，使用预分配的整型数组或 `Map` 每帧清空并插入所有粒子索引，提供 `queryNeighbors(x, y)` 返回 3x3 宫格内邻居。
2. 编写 `FluidSolver.ts`：定义杯子内部圆角矩形边界（如 `x: 280 到 520`，`y: 170 到 520`），每帧跑 **2 个物理子步（Substeps）** 保证不穿透：
   - **密度与压力**：统计邻域权重和得到局部密度，按超出静止密度的差值沿连线施加排斥力（实现不可压缩与自然铺平液面）。
   - **重力与密度分层**：施加向下的重力 `g = 980`，对不同原料额外施加浮力修正 `(particle.density - avgNeighborDensity) * 420`，让 `1.38` 的糖浆稳稳沉底、`0.86` 的金酒浮在表层。
   - **粘滞与动态混色**：邻域粒子间按粘滞系数平滑速度差；按相对速度动态调整混色系数（静止 `0.0015` 保留分层边界，剧烈晃动时放大至 `0.035` 实现梦幻渐变融合）。
   - **防爆约束**：强制限制单粒子最大速度不超过 `850 px/s`，粒子总数硬上限锁死为 `850` 颗。
3. 接入鼠标临时测试：按住左键持续从杯口正上方发射所选原料粒子（每帧发射 3 颗），按键盘 `1`–`6` 切换原料。

- **验收标准（DoD）：** 先倒蓝柑糖浆再倒银河苏打水再倒紫罗兰金酒，杯中呈现清晰的三层霓虹分层；持续倾倒液面平稳上升不炸飞，总帧耗时小于 6ms。
- **卡点止损方案：** 如果密度分层出现上下剧烈震荡，把浮力修正系数降半并略微提高速度阻尼（每帧 `vx *= 0.992`）。

### 步骤 3：接入冰块浮力耦合与 Web Audio 零素材 ASMR 引擎
> **核心产物：** `IceRigidBody.ts`、`LiquidAudioEngine.ts`

**执行动作：**
1. 编写 `IceRigidBody.ts`：冰块物理碰撞体采用圆形近似（半径 `26px`，最多允许投入 5 块），受重力、流体粒子向上浮力（当冰块浸入粒子密度区时施加向上托举力）和角速度阻尼驱动；渲染时按冰块角度画成带折射边缘的半透明圆角冰块。
2. 在冰块撞击杯壁或冰块互撞时，计算法向冲量 `impulse`，加一个 `40ms` 的单块冷却防抖，触发回调 `onIceCollision(impulse, size)`。
3. 编写 `LiquidAudioEngine.ts`（零外部音频文件）：
   - **主总线防爆音**：所有声音必须先汇入 `DynamicsCompressorNode`（`threshold: -18`, `knee: 12`, `ratio: 6`）再进主音量和输出端。
   - **倒酒声**：循环白噪声过带通滤波（`Q = 5.5`），根据当前杯内粒子占比 `fillRatio` 将中心频率从 `320Hz` 曲线推升至 `1350Hz`，随机叠加 `35ms` 正弦向上扫频的“咕咚”微气泡音。
   - **冰块叮当声**：收到 `onIceCollision` 后并联 3 个非整数倍频正弦振荡器（`1.0 / 2.756 / 5.404` 倍基频 `2400–3100Hz`）加 `5ms` 高频瞬态噪声冲击，指数快速衰减。
   - **碳酸嘶嘶声**：持续白噪声过 `4800Hz` 高通滤波，音量严格正比于当前杯中带 `fizz` 属性的粒子数量。
   - **摇杯水声**：白噪声过 `600Hz` 宽带通滤波，音量绑定杯子晃动加速度。

- **验收标准（DoD）：** 戴上耳机闭眼听——倒酒时能清晰听出杯子由空变满的音调爬升；点击“加冰”时冰块落水激起浪花并响起清脆真实的玻璃碰冰声；倒入苏打水后持续响起细腻的碳酸嘶嘶声，全场无任何爆音破音。
- **卡点止损方案：** 若冰块多边形旋转碰撞复杂，坚持使用圆形碰撞体做物理、圆角矩形做视觉渲染即可，肉眼完全无违和感。

### 步骤 4：打磨核心调饮手感（倾倒动画、抓杯摇晃与装饰）
> **核心产物：** `BottleRack.tsx`、`ActionDock.tsx`

**执行动作：**
1. **自然倾倒交互**：左侧排列 6 支极简霓虹轮廓酒瓶。按住某支酒瓶（或选中后长按酒杯上方）时，瓶身以弹簧缓动飞到杯口上方并平滑倾斜 115 度，瓶口对准液面持续流出对应颜色的流体束，松手后酒瓶优雅回位。
2. **灵魂“摇杯混色”机制**：
   - **自由晃杯**：鼠标直接按住酒杯拖拽左右/上下甩动，将杯体位移速度作为反向惯性加速度注入所有液体粒子和冰块，同时自动触发液面飞溅与冰块连环清脆碰撞声。
   - **一键雪克盖（Shaker）模式**：点击“摇匀”按钮，杯口落下金属雪克盖封顶，允许玩家狂甩鼠标 3 秒而不洒出一滴，液体剧烈翻滚彻底混出高级莫兰迪/赛博渐变色。
3. **点睛装饰物**：底部栏支持点击投入「冰块」「鲜切柠檬片」「薄荷叶」「发光搅酒棒」（搅酒棒可随鼠标伸进杯中直接拨动液体粒子与冰块，解压感极强）。

- **验收标准（DoD）：** 全程单手纯鼠标操作，从“选酒倾倒 → 投冰 → 插棒搅动/摇杯混色 → 加薄荷叶”一气呵成，无需文字教程即可直觉上手。

### 步骤 5：暗夜氛围升维与前景玻璃质感层
> **核心产物：** `GlassOverlay.ts`、暗夜 UI 精修

**执行动作：**
1. 编写 `GlassOverlay.ts`（叠在 WebGL2 画布正上方的透明 2D Canvas）：
   - 绘制通透感极强的直身古典杯/高球杯轮廓：左右两条锐利细高光条、底部厚重玻璃底座折射层、杯口微弱椭圆反光。
   - 在液体区域内部绘制随机缓慢上浮的微小白色气泡点（速度与 `fizz` 挂钩）。
   - 当杯中投入冰块超过 2 块后，在杯壁外侧逐渐浮现柔和的“冷饮凝结水珠”效果。
2. **环境光实时联动**：根据当前杯中液体的平均 RGB 颜色，动态改变背景墙面一团超大半径高斯模糊霓虹光晕的颜色（CSS `radial-gradient` 平滑过渡），让整张画面像真实吧台灯光穿透酒杯。
3. **深夜雨声白噪音开关**：在右上角加一个极简「窗外夜雨」开关——用纯 Web Audio 粉红噪声 + `850Hz` 低通滤波 + 缓慢 LFO 模拟窗外绵密雨声，叠加背景微弱斜落雨丝线条。

- **验收标准（DoD）：** 暗环境观看屏幕时视觉高级且通透；界面文字极度克制，75% 以上屏幕空间留给发光的酒杯与液体动态。

### 步骤 6：纯本地风味结算、浪漫命名与酒单导出
> **核心产物：** `namingRules.ts`、`MenuCardModal.tsx`

**执行动作：**
1. 编写 `namingRules.ts`（100% 本地确定性算法，零 AI 依赖）：
   - 统计杯中各类原料粒子占比，加权算出最终的 **五维风味值**（酸、甜、苦、烈、爽）。
   - 计算“分层指数”（底部与顶部液体的色彩欧氏距离），自动识别出你是「完美分层特调」还是「狂野摇匀混饮」。
   - 用规则引擎拼装高级感酒名与一句深夜短签（例如：高烈度 + 蓝色主导 + 高分层 → **《午夜深海断层 / Abyssal Stratification》**，短签：“适合在凌晨两点写完最后一个 Bug 后独饮”）。
2. 编写 `MenuCardModal.tsx`：点击「完成调饮」弹出磨砂玻璃酒单卡片，包含：
   - 自动截取当前 WebGL + 玻璃前景合成的高清酒杯快照；
   - SVG 绘制的五维风味雷达图与配料百分比刻度条；
   - **一键保存高清明信片 PNG**（`html-to-image`）；
   - **一键复制配方 URL**：将原料配比、冰块数、摇晃度压缩为 Base64 拼入 `location.hash`（如 `#r=e30...`），打开链接直接自动重演并还原这杯酒。

- **验收标准（DoD）：** 调出三杯截然不同的酒，生成的酒名、短签、雷达图均合理且极具格调；导出的 PNG 清晰无黑屏缺失（WebGL context 需开启 `preserveDrawingBuffer: true` 或在渲染帧回调内同步截图）。

### 步骤 7：极客透视模式、多端压测与离线打包
> **核心产物：** `DebugInspector.tsx`、静态构建产物、备播演示视频

**执行动作：**
1. 编写 `DebugInspector.tsx`：绑定全局快捷键 **`D`**，按下后屏幕右侧平滑滑出半透明极客透视抽屉，主画布支持一键切换三种渲染视角：
   - **视角 1（成品流体）**：完整融球 + 玻璃质感；
   - **视角 2（物理骨架）**：直接绘制原始离散粒子点、速度矢量与空间哈希网格线；
   - **视角 3（Pass 1 密度热力图）**：直出离屏 FBO 密度场伪彩图；
   - **底部实时示波器**：从 Web Audio 主总线接一个 `AnalyserNode`，实时跳动倒酒共振频谱曲线与冰块碰撞波形。
2. **分辨率与音响实测**：在 `1920x1080` 与 `1280x720` 分辨率下测试布局无遮挡；连接外接音箱开大音量实测冰块声是否刺耳，微调 `DynamicsCompressorNode` 与高音衰减。
3. **双保险打包交付**：
   - 执行 `npm run build` 打包纯静态 `dist`，部署到免费边缘静态托管（EdgeOne Pages / Cloudflare Pages）供在线访问；
   - 本地保留 `npm run preview` 离线运行环境，并用 OBS 录制一段 **40 秒带清晰收音的 1080P 60FPS 备播演示视频**。

- **验收标准（DoD）：** 断掉电脑 Wi-Fi 后全流程从开屏、调酒、听声、按 `D` 键透视到导出 PNG 卡片 100% 离线丝滑跑通，零报错、零卡顿。
